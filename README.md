# Moroccan Footballers

A static, responsive squad-depth dashboard for the Morocco men's national team, mapped to a 4-2-3-1 formation.

## Run locally

No package install is required. From this folder, run:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Deploy to Vercel

Import this folder as a project or deploy it with the Vercel CLI. It is a static site: no build command, framework preset, database or environment variables are required.

## Features

- Click any of the 11 positions on the 4-2-3-1 pitch to inspect its depth.
- Switch between all options and November squad selections.
- Search the player pool by name or primary position.
- Open player cards for squad status and positional context.
- Toggle between light and dark themes.
- Responsive layout for desktop, tablet and mobile.

## Roster methodology

The "Latest squad" group follows the 26-player senior selection announced on 4 November 2026. "Recent call-up" contains additional names from the 29-player selection announced on 17 September 2026, excluding players included in the November group. Tactical position mapping is editorial and is not an official team sheet; players with positional versatility can appear in multiple depth lists.
